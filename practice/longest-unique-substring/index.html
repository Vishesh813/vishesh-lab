Longest unique substring

Find the length of the longest substring that contains no repeated characters.

Medium O(n) time O(k) space Strings
Try it first. This page gives hints, not a solution. Read the examples, work an approach on paper, then open a hint if you stall. The related module is linked in the sidebar.

Problem

Given a string s, return the length of the longest substring that does not contain repeating characters. A substring is a contiguous sequence of characters.

Examples

Inputs = "abcabcbb"Output3NoteThe answer is "abc".
Inputs = "bbbbb"Output1NoteThe answer is "b".
Inputs = "pwwkew"Output3NoteThe answer is "wke".

Constraints

  • 0 ≤ s.length ≤ 100,000
  • s contains printable ASCII characters

Hints

Open one at a time. The later hints get more specific.

Hint 1

Maintain a window with no duplicates.

Hint 2

Store the last index of each character.

Hint 3

When a duplicate appears, move the left edge past its previous position.

After you solve it

State the time and space cost, then compare it with the target in the sidebar. If your solution is slower, ask which operation is repeated and whether a different structure makes it constant-time.
