How the track works

Learn the move, then make the move.

Each module gives you one mental model, a blueprint, a set of decisions with their costs, and a prompt to design out loud. The checklist is what you can explain, not what you have skimmed.

  1. 01Clarify the user, scale and the two hardest requirements.
  2. 02Estimate QPS, storage and the read/write split.
  3. 03Draw the smallest end-to-end path before adding parts.
  4. 04Pick one hard component and go deep.
  5. 05Break it on purpose, then close with trade-offs.
